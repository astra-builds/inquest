# Inquest

Developer-focused LLM evaluation platform. See [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) for the approved MVP architecture.

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

- `npm run dev` — start the development server
- `npm run build` — production build
- `npm run lint` — ESLint
- `npm run typecheck` — TypeScript check
- `npm run test` — Vitest unit tests

This is the initial application shell. Product features are not yet implemented.
